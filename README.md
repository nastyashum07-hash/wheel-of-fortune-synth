# Wheel of Fortune — Синтез непредсказуемости

Интерактивный веб-синтезатор по мотивам карты «Колесо Фортуны»: два голоса, управляемая случайность, 90-секундная композиция с плавным развитием.

## Запуск

Нужен современный браузер с Web Audio API. В корне проекта:

```sh
python3 -m http.server 8000 --directory dist
```

Откройте http://localhost:8000 и нажмите ☉ или персонажа: браузер разрешает звук после действия пользователя. Сборка, npm-зависимости, внешние аудиофайлы и API-ключи не нужны. Для прослушивания стереопанорамы используйте наушники.

## Звук

- «Нисхождение»: треугольный основной осциллятор и синусоидальный субголос, панорама −0,82.
- «Вознесение»: синусоидальный основной осциллятор и тихий треугольный обертон, панорама +0,82.
- У каждой партии собственные gain → low-pass → waveshaper; далее сухой тракт и параллельные delay с обратной связью, convolution reverb, chorus с LFO. Ветви сходятся в StereoPannerNode соответствующего голоса.
- Общий выход: low-pass → compressor → gain → AudioContext.destination.
- Параметры сглаживаются через setTargetAtTime; огибающие нот используют линейные и экспоненциальные рампы. Планировщик работает каждые 50 мс, планируя звук на 140 мс вперёд.

## Музыка и управление

Каждый запуск получает новый seed через crypto.getRandomValues, тональность и два восьмишаговых мотива в минорной пентатонике. «Судьба» увеличивает вероятность изменения мотива и отдельных нот, размер интервалов и вариативность силы нот. Это программная случайность, не квантовый источник. В финале мелодия тяготеет к опорным ступеням. Повтор создаёт новый мотив в той же тональности и сохраняет хвосты эффектов.

☉ — Призыв (90 секунд); ◇ — Печать тишины; ∞ — Вечное возвращение. Пробел — запуск/завершение; Z/X — ноты двух голосов; Esc — завершение. Персонажи включают голоса и эффекты, колесо меняет срез фильтра. Луна, звезда, ромбы и четыре внутренних символа меняют значения вверх/вниз; направление разворачивается на границах. В автоматическом режиме ручная правка приоритетна 7 секунд. Буквы на ободе декоративные; это не отдельные шаговые кнопки.

90-секундная форма: 0–26 с зарождение, 26–64 с развитие и кульминация, 64–90 с растворение. В одиночном исполнении генерация нот затихает на 77–86 с, последние 4 секунды оставлены эффектам. В режиме повтора финальное затихание не применяется, аудиограф не перезапускается.

## Проверки

```sh
for file in dist/*.js; do node --check "$file"; done
node tests/verify.cjs
```

Тесты проверяют генератор мелодии, диапазоны, разводку аудиографа с тестовыми узлами Web Audio, завершение и повтор. Они не заменяют прослушивание реального браузера или измерение записанного стереосигнала.

## Структура исходников

- `dist/state.js` — состояние и ограничение диапазонов параметров.
- `dist/audio.js` — создание аудиографа, голоса и эффекты.
- `dist/melody.js` — независимый генератор музыкальных мотивов.
- `dist/sequencer.js` — партитура и планирование нот.
- `dist/interface.js` — нажатия, клавиатура и вращение колеса.
- `dist/animation.js` — визуальное движение и измерение выходного сигнала.
- `dist/app.js` — загрузка иллюстраций и вступительный экран.
- `dist/style.css` — актуальные стили, сгруппированные по компонентам.

Скрипты подключены в указанном в HTML порядке без сборщика. Состояние объявляется в `state.js`, функции остальных файлов используют его; запуск интерфейса выполняется после загрузки всех частей. Неиспользуемые макеты и стили предыдущих итераций удалены.

Реальная проверка звука: запустите `python3 -m http.server 8000` из корня и откройте `http://localhost:8000/tests/audio-browser.html`. Кнопка запускает OfflineAudioContext: обе партии, панорама, четыре эффекта, отсутствие перегрузки в тестовых фрагментах и нулевая мастер-громкость.
